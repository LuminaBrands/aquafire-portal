Border Beam

Vanilla port of the border-beam npm package, rebuilt as plain CSS so it runs in this build-free portal. Wrap any element in .af-beam — children render untouched, the effect is purely additive.

This browser lacks @property or mask-composite support, so the beam is disabled. Content still renders normally.
